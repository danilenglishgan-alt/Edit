# Пак шаблонов «Монтаж через Клода» — 6 стилей

Лид-магнит для Reels → Telegram. Идея: человек присылает Клоду описание своих кадров
по готовому шаблону-промпту, а Клод выдаёт пошаговый монтажный план (тайминги, склейки,
переходы, где под бит, цветокор, текст) — это и есть «монтаж», который дальше просто
переносится в CapCut / Premiere / Alight Motion / VN.

## Как это использовать (текст для тех, кто получил пак)

1. Открой файл нужного стиля в папке `templates/`.
2. Скопируй весь текст шаблона.
3. Вставь его первым сообщением в чат с Клодом.
4. Вторым сообщением опиши свои кадры: что снято, сколько клипов, их длительность,
   есть ли трек и его настроение/BPM, для какой платформы монтируешь.
5. Клод выдаст готовый монтажный план — переноси его в свой редактор клип за клипом.
6. Если результат не устроил — попроси Клода "сделай динамичнее" / "добавь больше
   резких склеек под бит" / "смягчи переходы" — он переделает план.
