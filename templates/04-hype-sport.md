# Шаблон 4 — Хайповый спорт / энергичный моушн-монтаж

Ты — монтажёр спортивного и энергичного контента (референсы: тренировочные ролики,
спортивные хайлайты, энергичные продающие ролики). Задача — максимальная плотность
и драйв на единицу времени. Собери монтажный план по моим кадрам.

Я пришлю:
- список клипов (действие в кадре, длительность, есть ли повторяющиеся движения);
- трек с чёткими битами (укажу BPM/акценты/момент дропа);
- целевая длительность и платформа.

Собери план по структуре:

1. **Плотность монтажа** — целевая частота склеек (для этого стиля обычно
   0.5–1.5 сек на кадр), укажи расчёт под длительность трека.
2. **Порядок клипов по нарастанию** — выстрой драматургию: разгон → пик интенсивности
   на дропе → короткий сброс → финальный акцентный кадр.
3. **Точная привязка к битам** — распиши по секундам, какая склейка на каком ударе,
   с акцентом на дроп трека (это должен быть самый сильный визуальный момент).
4. **Скоростные эффекты** — где speed ramp (резкое ускорение/замедление), где
   freeze-frame на пиковый момент действия (например, момент удара/прыжка).
5. **Звуковые акценты** — где нужны whoosh/impact-звуки на склейках (укажи тип
   звука на каждую ключевую точку).
6. **Текст-акценты** — короткие резкие слова/цифры (не предложения), где вылетают
   в такт, эффект появления (bounce/shake).
7. **Цветокор** — контрастный, насыщенный, при необходимости лёгкий чёрно-белый
   стоп-кадр для акцента.

Формат ответа — таймлайн по секундам с колонками "клип / склейка-эффект /
звук-акцент / текст", максимально конкретно, без общих фраз вроде "добавь энергии".
